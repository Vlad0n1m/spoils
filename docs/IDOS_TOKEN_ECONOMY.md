# SPOILS — экономика на токене SPOILS (iDos-издание)

Дата: 05.10.2026. Решение принято агентом по поручению Влада («сам принимай решение, делай»).
Факты о платформе — `docs/idos-token-research.md`. Механика игры — `docs/GAME_DESIGN.md`.

## 1. Продуктовая история в одном абзаце

SPOILS — экстракшен-шутер: зашёл на карту, налутал, выжил — вещи твои; умер — вещи уходят в
«пул потерянного». Токен SPOILS (Solana, выпущен через iDos) — **деньги этого мира**: за него на
складе снабжения можно купить ящик с настоящей вещью из пула, стартовый набор, кредиты или
поддержать разработчиков. Игра **не печатает** вещи за токены: каждый ящик — это вещь, которую
кто-то потерял в рейде; кончились потери — ящик закрыт. Чем меньше вещей в пуле и чем больше их
покупают, тем дороже ящик. Потраченные токены уходят в долю разработчика на iDos и (фаза 2)
возвращаются игрокам выплатами за лут — игра не может выплатить больше, чем в неё вложили.

## 2. Что iDos позволяет (и что нет)

| Можно | Нельзя |
|---|---|
| списать SPOILS с игрового баланса через магазин iDos (наш сервер вызывает покупку с билетом игрока и видит списанную сумму) | цену в долларах (`AmountUsd`) для нашего токена: iDos не знает курс, списывает 0 — проверено 05.10, оффер удалён |
| прочитать баланс игрока | маркетплейс iDos за крипту |
| донат на чейне (`DonateToDeveloper`) | почтой/переводом отправить крипту |
| выплаты игрокам из доли разработчика — `ServerGrantPolicy: Backed` (включает только iDos: запись `Main` защищена) | наш сервер не может выдать SPOILS, пока Backed не включён |

## 3. Фаза 1 — запускается сейчас (траты)

Цена задаётся в центах, сервер переводит в SPOILS по живому курсу Jupiter (кэш 60 с, без курса
свежее 10 мин — покупки закрыты), округляет **вверх** до 1 000 SPOILS и платит офферами iDos
`pay_100k` × a + `pay_1k` × b. Каждая цена после всех множителей — от 1¢ до $1.

| Товар | Цена | Откуда берётся | Ограничения |
|---|---|---|---|
| Ящик «обычный» | 5¢ × динамика | случайная обычная вещь **из пула потерянного** | нет в пуле → «распродано»; блокировка торговли 3 рейда |
| Ящик «редкий» | 15¢ × динамика | редкая из пула | то же |
| Ящик «эпический» | 40¢ × динамика | эпическая из пула | то же; легендарные не продаются никогда |
| Стартовый набор | 10¢ | как в основной версии (3 пистолета, броня 1, патроны, бинты, аптечка) | ≤ 3 в день (общий лимит наборов) |
| 2 000 CR | 5¢ | кредиты (только на торговцев и CR-рынок, в токен не выводятся) | ≤ 5 в день |
| «Supporter» / «Patron» | 25¢ / $1 | донат разработчикам → косметический титул | без лимита |

**Динамика ящика:** `цена = база × дефицит × спрос`;
дефицит = clamp(√(40 / вещей этой редкости в пуле), 0,8 … 1,5);
спрос = min(1,5; 1 + 0,02 × продано ящиков этого вида за 24 ч).
Пул большой — ящик дешевле базы (до −20 %), пул пустеет — дороже (до +50 %), ажиотаж — ещё до +50 %.
Пул никогда не опускается ниже `POOL.MIN_RESERVE` и ниже 5 вещей нужной редкости.

## 4. Рынок между игроками (CR)

CR-рынок (из основной версии) включён и в iDos-издании, без SOL. Новое правило: **лот не может
стоить дороже цены игры** — для предметов, которые продают торговцы, потолок = цена торговца;
для остальных — прежний коридор 0,5×–4× индекса. Перекупить у торговца и продать дороже нельзя.

## 5. Почему не сломается

- **Инфляция предметов:** ящики только перекладывают вещи из пула (смерти, MIA), не создают их.
  Пул пополняется боями; резерв не трогаем.
- **Дефицит:** цена растёт по мере опустошения пула, при резерве — распродано; рейды пополняют пул.
- **«Игра печатает оружие за токены»:** нет — см. выше; купленная вещь 3 рейда не торгуется.
- **Перепродажа выше игры:** потолок на CR-рынке.
- **Токен → CR → токен:** CR в токен не конвертируется вообще (одностороннее), выплаты фазы 2
  только за лут и только из доли разработчика.
- **Ошибка оплаты:** сервер выдаёт товар только после того, как iDos вернул списание ровно на
  нужную сумму; если первая часть оплаты прошла, а вторая нет — заказ `refund_owed`, ничего не
  выдано, сумма записана для ручного возврата.

## 6. Фаза 2 — после включения `ServerGrantPolicy: Backed` у Main (просим iDos)

- **Скупка лута за SPOILS:** при экстракте можно продать вещь не за CR, а за SPOILS по цене
  ≈ 60 % цены ящика её редкости; вещь уходит в пул (следующему покупателю ящика). Выплата —
  только из доли разработчика (Backed), с дневными лимитами `PerPlayerDailyTokens` /
  `TitleDailyTokens`.
- **P2P-рынок за SPOILS:** покупатель платит через магазин (в долю разработчика), продавцу
  начисляется цена − 5 % (Backed) — эскроу и предмет у нас, деньги у iDos. Потолок — цена ящика.
- Пока Backed выключен, фаза 2 не включается: выплачивать нечем (а IOU вместо денег — обман).
