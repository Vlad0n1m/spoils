# Дизайн игры и экономика — черновик v2

Рабочее название не выбрано. Цены, комиссии и проценты — черновик: денежные цифры выбирает Влад,
игровые (урон, прочность, шансы) подбираем на плейтестах. Где цифра «для примера» — так и помечено.

v2: вместо общего взноса — снаряжение, которое игрок берёт с собой. Одна арена для всех.
Экономику строят игроки: игра никому не платит из своего кошелька.

---

## 1. Суть в одном абзаце

Extraction-шутер с видом сверху (как ZombsRoyale) на Solana. Игрок берёт со своего склада
снаряжение и заходит на большую карту к другим игрокам. Убил — забрал то, что с него уцелело.
Вышел через точку выхода — всё, что нёс, твоё. Умер — потерял. Вещи стоят реальных денег:
их покупают и продают друг другу на маркетплейсе за SOL. Потерянные вещи не исчезают, а
возвращаются на карту в сундуки и к боссам. Игра зарабатывает на первичной продаже вещей
и на комиссии с оборота, но никогда не платит игрокам сама.

---

## 2. Три главных правила экономики

1. **Игра никому не платит.** SOL ходит только так: игрок → игрок (маркетплейс) и игрок → игра
   (покупка новых вещей, комиссии, ремонт, патроны). Из кошелька игры выплат нет.
2. **Вещи не создаются из воздуха.** Новые вещи появляются только двумя путями: стартовая раздача
   (§7а) и первичная продажа в магазине игры ограниченными партиями. Всё остальное, что лежит в сундуках, — потерянное игроками.
3. **Вещи медленно исчезают.** Износ и ремонт постепенно уничтожают вещи. Без этого вещей станет
   слишком много, цены упадут, и экономика умрёт.

---

## 3. Словарь

| Термин | Что значит |
|---|---|
| **Склад** | Вещи игрока вне матча. Можно продать, вывести как NFT, взять в матч |
| **Снаряжение (лоадаут)** | Что игрок взял с собой в матч. Его стоимость — риск игрока |
| **Бесплатный набор** | Пистолет и бинты. Выдаётся всем, не продаётся, не теряется |
| **Прочность** | 0–100. Падает от использования. На 0 вещь уничтожена навсегда |
| **Пул потерянного** | Вещи, которые сломались при смерти или остались невынесенными. Из него наполняются сундуки и боссы |
| **Маркетплейс** | Продажа вещей между игроками за SOL. Игра берёт комиссию |
| **Казна** | Кошелёк игры. Только принимает деньги, ничего не выплачивает |
| **Точка выхода** | Зона на карте: простоял в ней N секунд — вынес всё на склад |

---

## 4. Цикл игрока

```
Склад → собрал снаряжение → вещи заблокированы → матчмейкинг (одна арена)
  → высадка → лут / бой / боссы → выход ИЛИ смерть ИЛИ время вышло
  → итог: что вынес, что потерял → склад → продать / починить / снова в бой
```

Новичок без денег заходит с бесплатным набором. Ему нечего терять, и он может вынести
настоящие вещи — так игра затягивает новых игроков.

---

## 5. Жизненный цикл вещи

У каждой вещи свой ID и одно состояние в каждый момент:

| Состояние | Где вещь | Куда может перейти |
|---|---|---|
| `in_stash` | на складе | `listed`, `in_raid`, `withdrawn`, `destroyed` (ремонт невозможен) |
| `listed` | выставлена на маркетплейс | `in_stash` (снял), `in_stash` другого игрока (купили) |
| `in_raid` | на игроке в матче, заблокирована | `in_stash` (вышел), `on_ground` (умер, уцелела), `lost_pool` (умер, сломалась / время вышло) |
| `on_ground` | лежит на карте после смерти | `in_raid` у того, кто подобрал, `lost_pool` (конец матча) |
| `lost_pool` | в пуле потерянного | `in_chest`, `in_boss`, `treasury` (налог, см. §7) |
| `in_chest` / `in_boss` | спрятана в сундуке / у босса в матче | `in_raid` у нашедшего, `lost_pool` (не нашли) |
| `withdrawn` | выведена в кошелёк как NFT | `in_stash` (завёл обратно) |
| `destroyed` | уничтожена навсегда | — |

Правило: **у каждого перехода есть запись в журнале** (кто, когда, из какого матча). Вещь не может
быть в двух местах сразу и не может пропасть без записи.

```
          первичная продажа
 Казна ──────────────────────► Склад игрока ◄──── маркетплейс ────► Склад другого
                                   │  ▲
                          взял в   │  │ вынес
                          матч     ▼  │
                                В матче ──── смерть, уцелела ───► На земле ──► подобрал
                                   │                                   │
                       смерть, сломалась / время вышло        никто не подобрал
                                   ▼                                   ▼
                              Пул потерянного ◄────────────────────────┘
                                   │
                    следующие матчи: сундуки и боссы (прочность ниже)
```

## 6. Смерть, поломка и вынос

- **Смерть:** каждая вещь на игроке проверяется отдельно.
  - С шансом **50%** (решено Владом) — ломается и уходит в пул потерянного. Залутать её нельзя.
  - Иначе — падает на землю с потерей прочности, подобрать может кто угодно.
- **Бесплатный набор** не ломается и не выпадает.
- **Вышел через точку выхода:** всё, что нёс, — на склад. И своё, и найденное.
- **Время вышло:** всё, что было на игроке, — в пул потерянного.
- **Вылет:** персонаж остаётся на карте и уязвим, можно переподключиться.

Почему поломка, а не всё убийце: иначе один сильный игрок за вечер собирает всю экономику,
а у остальных пропадает смысл. Поломка отправляет часть вещей обратно в мир — их найдут другие.

---

## 7. Сундуки, боссы и «99%»

Потерянные вещи возвращаются в следующие матчи:

- **Сундуки:** вещи из пула потерянного, в основном обычные и редкие. Плюс расходники.
- **Боссы:** NPC-охранники с лучшими вещами из пула. Дерутся сильно, лут ценный — точка конфликта на карте.
- **Прочность при возврате:** вещь возвращается с прочностью на **N% ниже**. Это и есть «99%»:
  вещи, которые ходят по кругу, постепенно изнашиваются и исчезают.
- **Налог казны:** из пула потерянного казна забирает ~1% вещей по стоимости и выставляет их на
  маркетплейс как обычный продавец, по рыночной цене. Это доход игры. Решено Владом.
  Казна не демпингует: не ставит цену ниже минимальной на рынке, чтобы не обрушить цены игрокам.
- **Пул пустой** (старт игры) — в сундуках только расходники. Поэтому на старте казна засевает
  пул частью первой партии вещей, иначе в сундуках будет пусто.

---

## 7а. Стартовая раздача (решено Владом)

На старте вещи не продаются, а раздаются бесплатно. Цель — наполнить экономику и набрать первых игроков.

- **Кому:** первые N кошельков, один набор на кошелёк (и на аккаунт iDos).
- **Что в наборе:** оружие обычной/редкой редкости, броня, рюкзак. Несколько легендарных — по розыгрышу,
  чтобы с первого дня было за чем охотиться.
- **Засев мира:** часть раздачи сразу уходит в пул потерянного, чтобы в сундуках и у босса было что найти.
- **Защита от ферм:** розданную вещь нельзя продать, пока её владелец не сыграл K матчей (или до даты T).
  Иначе люди создадут сотню кошельков, заберут наборы и сразу сольют их на маркетплейс, обрушив цены.
  Потерять в бою или вынести с чужого трупа такую вещь можно — тогда у нового владельца она торгуется сразу.
- **Как игра зарабатывает в период раздачи:** комиссия маркетплейса, расходники, ремонт, налог с пула.
  Первичная продажа включается позже, когда понятны рыночные цены.

## 8. Как зарабатывает игра

| Источник | Как работает |
|---|---|
| **Первичная продажа** | После стартовой раздачи казна выпускает новые вещи ограниченными партиями и продаёт за SOL. Кроме раздачи, это единственный способ создать новую вещь. Чем меньше партия, тем дороже вещи на вторичке |
| **Комиссия маркетплейса** | X% с каждой сделки между игроками, как в Steam. Чем живее рынок, тем больше доход |
| **Ремонт** | Восстановить прочность — платно. Максимальная прочность после каждого ремонта снижается: вещь всё равно когда-нибудь умрёт |
| **Расходники** | Патроны и аптечки продаёт только казна, их тратят каждый матч. Стабильный доход |
| **Налог с пула потерянного** | ~1% потерянных вещей казна продаёт на маркетплейсе (§7) |

Чего игра **не делает:** не выплачивает SOL, не выкупает вещи у игроков (нет «слить в контракт»),
не выставляет ботов против игроков в обычных матчах.

## 9. Как зарабатывают игроки

- **Убийства:** забрал уцелевшие вещи убитого, вынес, продал.
- **Лут и боссы:** нашёл редкое оружие в сундуке или у босса — продал.
- **Перепродажа:** купил дешевле, продал дороже. Рынок строят игроки.
- **Охота на богатых:** с бесплатным набором риск ноль, а убитый богач может отдать полный комплект.

Цены задаёт рынок. Игра цены не назначает, кроме первичной продажи и расходников.

## 10. Вещи и баланс

**Главное правило: снаряжение даёт преимущество, но не решает бой.** Лучшее оружие примерно в 1.5–2
раза эффективнее стартового, а не в 10. Иначе бедные перестанут заходить, и богатым не на ком будет
зарабатывать.

### Оружие (черновик)

| Оружие | Урон | Скорострельность | Дальность | Магазин | Роль |
|---|---|---|---|---|---|
| Пистолет | 15 | средняя | средняя | 12 | бесплатный набор |
| Автомат | 12 | высокая | средняя | 30 | основное |
| Дробовик | 8×6 дробин | низкая | близкая | 5 | засады, здания |
| Винтовка | 60 | очень низкая | дальняя | 5 | контроль выходов |

**Редкость:** обычная / редкая / эпическая / легендарная — +0 / +10 / +20 / +30% к урону или скорострельности.
Легендарные — только из первичных партий и у боссов.

### Остальное
- **Броня:** 3 уровня, поглощает 20 / 35 / 50% урона, изнашивается от попаданий.
- **Рюкзак:** 3 размера — сколько вещей можно вынести за раз.
- **Расходники:** бинт (+25 HP), аптечка (+75 HP), патроны по типам.
- **HP:** 100, регенерации нет. Кусты скрывают, пока не стреляешь.

## 11. Карта и матч

| Параметр | Черновик |
|---|---|
| Карта | Большая, с зонами: лес, деревня, склады, база босса |
| Игроков | 20–30 на карту в MVP, дальше — больше |
| Длительность | 10–12 минут |
| Фаза 1 | Первые 2 минуты выходы закрыты |
| Точки выхода | 3–5, часть закрывается к концу. Стоять 10 сек, урон сбрасывает отсчёт |
| Над точкой | видно, что кто-то эвакуируется — повод для засады |

Технически: на большой карте сервер отправляет каждому игроку только то, что рядом с ним.
Иначе трафик и нагрузка растут с размером карты.

## 12. Solana

- **Вещи = записи в игре, NFT — при выводе.** Пока вещь в игре, это запись в базе, и её можно
  честно заблокировать в матче и отобрать при смерти. Вывел в кошелёк — стала NFT, вне игры она твоя.
  Завёл обратно — снова игровая. У iDos уже есть инвентарь, предметы, маркетплейс и вывод в NFT.
- **Почему не держать NFT в кошельке во время матча:** чтобы отобрать её у убитого, нужен свой
  смарт-контракт с заморозкой. Это недели работы и аудит. Возможная следующая версия.
- **Расчёты:** покупки, комиссии, сделки маркетплейса — в SOL или токене игры через iDos.
- **Доказуемо честный лут:** до матча публикуем хеш зерна раскладки сундуков, после матча — само
  зерно. Хеш итогов матча (что кто вынес и потерял) пишем в Solana.

## 13. Честность и злоупотребления

| Проблема | Что делаем |
|---|---|
| Читы | Всё считает сервер, клиент только шлёт нажатия |
| Вход без проверки | Только по подписанному билету после блокировки снаряжения |
| Ферма бесплатными наборами (много аккаунтов собирают сундуки без риска) | Лимит бесплатных заходов, привязка к кошельку / устройству, ограничение ценности лута для аккаунтов без истории |
| Сговор (двое играют как команда) | Связь аккаунтов, жалобы, разбор матчей. Полностью не лечится |
| Накрутка оборота на маркетплейсе | Комиссия делает её невыгодной |
| Сервер упал посреди матча | Матч отменяется, все вещи возвращаются в состояние до матча |
| Двойное начисление | Каждый переход вещи — с ID матча, повтор не проходит |

## 14. Архитектура

```
 Игрок (браузер, внутри iframe на idosgames.com)
   │  клиент: Next.js + PixiJS
   │
   ├── HTTPS ──► Бэкенд (Next.js API + Postgres)
   │              • вход через iDos
   │              • склад, блокировка снаряжения, билет в матч
   │              • магазин, маркетплейс, ремонт, журнал вещей и SOL
   │              • пул потерянного → раскладка сундуков на матч
   │
   └── WebSocket ──► Игровой сервер (Colyseus, 20 тиков/с)
                      • бой, пули, урон, боссы, сундуки, выходы
                      • отправляет игроку только то, что рядом
                      • итоги матча на бэкенд (подпись HMAC)

 iDos: тайтл, вход, токен на Solana, пополнение/вывод, (если даст API) инвентарь и маркетплейс
 Solana: токен, NFT при выводе, хеши раскладки и итогов
```

Из snake-sol берём: Colyseus, матчмейкинг, расчёт с подписью и повторами, рендер на PixiJS, демо-режим.

## 15. MVP до 13.10 и потом

**MVP (реально за 10 дней, плотно):**
- 1 большая карта, соло, 4 оружия, броня, рюкзаки, расходники.
- Склад, сборка снаряжения, блокировка в матче.
- Поломка при смерти, лут с земли, вынос на склад, износ.
- Пул потерянного → сундуки, 1 босс.
- Магазин казны (первичная продажа и расходники).
- Маркетплейс между игроками — простой: выставил по цене, купили.
- Демо-режим с ботами для жюри.

**Потом:** вывод в NFT (если iDos не даст из коробки), редкости, несколько боссов, сезоны,
отряды, новые карты, NFT в эскроу-контракте.
